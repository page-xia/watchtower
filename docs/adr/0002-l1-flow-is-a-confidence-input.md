# ADR 0002: L1 逐笔成交是重要置信输入

## 状态

已采纳。

## 背景

标准 easy_tdx 可返回五档 L1 和成交回报，但不能返回历史 委托队列。逐笔成交是已经发生的成交事实，比可撤销的委托队列更适合作为本系统的成交方向分析输入。80 只股票、两个交易日的真实分钟事件研究显示，把 L1 方向作为唯一必需买入条件没有足够依据，但它对 A/B 分级、抛压否决和减 T 辅助判断有明确价值。相邻分钟共振修复后，去重的 L1 A 级好点率为 24.16%、平均净收益 0.338%，B 级为 21.99%、0.140%；差异存在但样本期过短。

## 决策

- 指数拐头放量、板块确认、个股低位结构和当前分钟放量是买 T 的硬条件。
- 逐笔成交回报是重要成交事实输入，优先用于识别买盘承接、放量抛压和大额成交差。
- 适度 L1 买盘支持将信号升级为 A 级共振。
- L1 中性或不可用时允许 B 级分钟量价代理。
- 明显 L1 抛压否决买 T。
- 所有接口和页面继续注明数据口径，不把逐笔成交或五档代理称为 委托队列 大单；后续不以 委托队列 作为统一口径。

## 后果

策略在普通行情源下仍可工作，但信号等级会反映数据质量。A/B 的表现需要在更长样本和不同市场阶段继续验证，不能用当前两日结果推断长期收益。

满足市场、板块、个股结构和量能硬门槛后，明显 L1 抛压的去重子样本为 66 个，好点率 19.70%、平均净收益 0.015%，低于无抛压正式候选的 23.63%、0.264%。因此当前保留抛压否决作为风险控制，但它仍需样本外复核，不视为已证明的长期优势。
